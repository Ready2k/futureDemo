Ambient Financial Agent Demo
Evolution Spec: Today vs 2028 vs 2030
1. Objective

Build an interactive demo that compares three eras of banking experience using the same core scenarios.

The purpose is to show the evolution from:

Today: manual banking through a dedicated bank app

2028: AI assistant embedded inside the bank app

2030: device-level personal AI orchestrating financial services across providers

The key message is:

Today: banking is something you open

2028: banking is something you ask

2030: banking is something that happens for you

The demo must preserve the existing 2028 experience and add:

a Today mode

a 2030 mode

a comparison framework so the same scenario can be shown in all 3 modes

2. Core Thesis
2028 thesis

The bank still owns the interface, but AI becomes the interaction layer.

2030 thesis

The interface is no longer the bank app. The interface is the user’s AI.
The bank still matters because it owns trust, regulated execution, fraud controls, and product depth.

Strategic message

Winning banks in 2030 will not just build better apps.
They will become trusted execution platforms inside personal AI ecosystems.

3. Demo Modes

The demo must support three selectable modes:

Today

2028

2030

Switching mode must not change the scenario, only how the experience behaves.

Example shared scenario:

“Can I afford a £900 holiday?”

This allows clean A/B/C comparison.

4. Comparison Model
A. Interface Layer
Today

Dedicated Barclays-style banking app

Bottom navigation

Static account views

Manual user navigation

User must find balances and calculate affordability themselves

Flow:
User → Bank App → Core Banking

2028

Existing demo experience

Barclays app shell remains

AI assistant sits inside the bank app

Structured cards, reasoning, support, policy approvals

Bank still owns interface

Flow:
User → Bank App + AI Assistant → Intent Engine → Policy Engine → Bank APIs → Core Banking

2030

No bank app as primary interface

Device/personal AI assistant becomes primary UI

Neutral assistant canvas

Bank appears as trusted provider/execution layer

Cross-provider financial orchestration

Flow:
User → Personal AI Assistant → Financial Agent Layer → Consent/Risk Guardrails → Bank Capability APIs → Payments/Open Banking → Core Banking

B. Financial Intelligence
Today

Shows data only

Example: balance and savings

User interprets financial meaning

2028

AI provides financial reasoning

Example: “You have £1,160 available after bills and savings goals.”

Includes affordability, category analysis, behavioural insight

2030

AI provides financial orchestration

Example: “You can book the £900 trip. I recommend paying from your travel budget and preserving your emergency buffer.”

Includes cross-account optimisation, delegated monitoring, automated financial decisions

C. Action Execution
Today

User performs every step manually

Select account, amount, confirm

2028

Assistant proposes actions

Policy engine evaluates

User explicitly approves higher-risk actions

2030

Assistant executes within user-defined rules and preferences

Example: “I restored your current account buffer by moving £400 from savings.”

Shows delegated execution with visible trust, consent and audit trail

D. Support Experience
Today

Separate support journey

User must explain issue and repeat context

2028

Assistant triages issues inside the banking experience

Can identify transaction, open dispute, escalate with context

2030

Assistant proactively detects issues and acts first

Can pause merchants, draft disputes, monitor anomalies, escalate seamlessly

Support becomes ambient protection

E. Bank Visibility
Today

Bank is the product and interface

2028

Bank is an AI-enabled platform and still owns customer interface

2030

Bank is a trusted financial execution and protection layer

Customer may interact mainly through personal AI, device assistants, or embedded agents

Bank still provides:

payments infrastructure

regulatory trust

fraud protection

product depth

human specialists

5. 2030 Demo Concept
Name

Ambient Financial Agent 2030

Do not use “Barclays Assistant” as the primary identity.
Barclays should appear as a trusted provider within the ecosystem.

Core story

The user does not consciously “go banking.”
They live, ask, approve, review, and delegate.

6. 2030 Narrative Scenes

Build a 2030 demo sequence using these scenes.

Scene 0 — Ambient life context

Start from phone home screen, lock screen, or assistant overlay.

User says:

“Do I have enough room to book the Manchester trip?”

Assistant replies with a financial summary, not a bank balance screen.

Scene 1 — Cross-provider financial view

Assistant responds across multiple financial sources, not only Barclays.

Example:

“Across your current account, savings and ISA, you’re in a healthy position. Booking this today would leave your monthly buffer intact.”

Scene 2 — Goal-aware action

User says:

“Book it with the best option and keep my emergency buffer safe.”

Assistant:

evaluates options

explains impact

chooses funding route

asks for high-level approval

This is goal-based orchestration, not simple transfer execution.

Scene 3 — Continuous support

Assistant detects an unusual recurring charge.

Example:

“I’ve spotted an unusual recurring charge from Northline Services. I’ve paused future payments and drafted a dispute. Do you want me to continue?”

Scene 4 — Delegated monitoring

User sets a standing intent.

Example:

“Keep my dining spend under control and move excess cash to savings every Friday.”

Assistant confirms policy and continues monitoring over time.

Scene 5 — Trust and execution view

Show a compact explanation panel:

Personal AI recommended action

Consent/policy checks passed

Barclays executed payment

Visa network credential used

Fraud monitoring active

This is critical for trust and bank relevance.

Scene 6 — Human specialist continuity

User says:

“Connect me to someone.”

Human specialist joins with full context already loaded.
No repetition, no restarting the issue.

Scene 7 — Strategic overlay

Show the 2030 architecture:

Personal AI / Device Assistant
↓
Financial Agent Orchestrator
↓
Preference & Goal Memory
↓
Policy / Consent / Risk Layer
↓
Bank Capability APIs
↓
Payments Networks / Open Banking / Commerce APIs
↓
Core Banking + Human Specialist Escalation

8. Bank Control Center

The bank app still exists in 2030, but as a secondary control plane.

Use it for:

reviewing permissions

changing limits

inspecting audit trail

disabling automations

managing identity and recovery

doing manual tasks if required

This should not be the main interaction surface.
